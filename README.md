# Griya Mayang Permai Jombang — MJ Property

Website Company Profile & Katalog Properti resmi **MJ Property (Interior & Exterior)** untuk kawasan hunian **Griya Mayang Permai Jombang** (Rumah Subsidi & Rumah Komersil Desain Scandinavian).

## Struktur Multi-Navbar (HP & Laptop)
- **Beranda (`#beranda`)**: Homepage ringkas (Hero minimalis + akses cepat Unit & Cek KPR).
- **Unit & Denah (`#unit`)**: Sub-menu *Katalog Unit* & *Denah 2D Interaktif + Spesifikasi*.
- **Kuisioner & KPR (`#kpr`)**: Sub-menu *Kuisioner Kelayakan KPR* & *Kalkulator Cicilan*.
- **Profil & Lokasi (`#profil`)**: Sub-menu *Lokasi & Promo* & *Profil MJ Property*.
- **Kontak (`#kontak`)**: Tim Marketing Resmi & Kanal Sosial Media.

## Menjalankan Proyek
```bash
npm run dev
```
